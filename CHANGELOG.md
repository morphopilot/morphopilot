# Changelog

## 0.1.0 — Initial open-source source release

- Portable MorphoPilot browser annotation application.
- Persistent volume upload, tiling, review, merged visualization, export, and deletion/restoration.
- Independent built-in and custom data categories with a current model per category.
- Native interactive segmentation Prompt inference and incremental fine-tuning; additional Auto stem and explicit Auto workflow.
- Own-server gateway and worker supervisor, pinned dependencies, separate official weight download.
- Synthetic examples, public project website, installation and contributor documentation, and regression checks.
- Complete reference coverage across all 25 synthetic Z slices, stronger overlays, explicit comparison views, and immediate, continuous Z playback.

No private research volumes or pretrained weights are bundled. This release does not claim a new biological benchmark or generalization result.
