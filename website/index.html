A closer look.

Does the model learn from every click?

Clicks guide the current segmentation. Model weights update when you explicitly confirm the annotation and start fine-tuning. Only eligible, confirmed training data from that category is used.

Can Auto mode work without prompts?

Yes. The added Auto stem supports image-only inference after conversion and training on reviewed image–mask pairs. Prompt fine-tuning and Auto training are separate stages. Evaluate your Auto checkpoint on data withheld from training before relying on its outputs.

Can I use my own large 3D images?

Yes. Upload single-channel ZYX TIFF, BigTIFF, NPY or NPZ volumes. The platform creates tiles, saves their locations, and lets you annotate and confirm them individually. Review all tiles to export the merged mask at the original volume dimensions.

Is this a commercial or clinical product?

This is an open-source research platform, not a clinically validated device. Project-generated code and synthetic assets are released under Apache 2.0. Upstream components and downloaded model weights retain their own licenses. No weights or private research datasets are bundled.

 SELF-HOSTED RESEARCH WORKSPACE

Bring the Studio
to your server.

Get the source from your configured repository or project release. GPU inference and training require an NVIDIA GPU and a compatible CUDA environment. No account with a hosting platform is required.

Prerequisites: Node.js 22 LTS or 24+, npm, Python 3.10–3.12, and Git. Run these commands from the project root on your server.

  1. Build the browser app.npm cinpm run build
  2. Install the GPU environment.bash deploy/install.sh gpu
  3. Configure storage and credentials..venv/bin/python deploy/configure.py

    Choose a workspace password when prompted. The default data and model folders are created locally.

  4. Download and verify the original model.bash deploy/download-model.shbash deploy/doctor.sh

    Model weights have their own upstream license and are downloaded separately.

  5. Start the workspace.bash deploy/start.sh

    Open http://127.0.0.1:8787 on the server, or forward port 8787 to your computer using the SSH instructions in the full guide.
